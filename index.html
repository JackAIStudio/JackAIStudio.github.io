JackAIStudio

吴杰克 Jack 的开源项目

jackskill 是一个 Agent Skill。装完之后，在 Agent 里输入 /jack， 就能调取跨平台自媒体真实数据、全部视频口播逐字稿，以及四个自研工具的规范。

安装

npx -y skills add JackAIStudio/jackskill -g --all

装完在 Agent 中输入 /jack；/jack list 看清单。

数据与索引

  • 数据站 —— 自媒体数据与逐字稿的可视化页面
  • jackskill/llms.txt —— 机器可读索引
  • llms.txt —— 本域名索引
  • data/videos.json —— 全部指标与逐字稿的单文件版本
  • github.com/JackAIStudio/jackskill —— 源码
